Dust2Glow - Cleaning Service Management System

Welcome to the official system documentation for Dust2Glow, an enterprise-grade Cleaning Service Management Platform built on PHP 8.2+ and Laravel 12. This documentation covers system installation, architecture, role management, customer booking workflows, wallet/reward engines, and administrative controls.

System Architecture Highlights

  • Backend Framework: PHP 8.2+ / Laravel 12 with Fortify authentication and Sanctum API security.
  • Frontend Stack: Responsive Blade Templates, Bootstrap 4, jQuery, Yajra DataTables, and SweetAlert2.
  • Database: MySQL 8.0+ with transactional integrity, foreign keys, and migration-driven schema management.
  • Role Security: Granular access control using Middleware guards (`can:admin`, `can:customer`, `can:view-audit-logs`).
  • Testing Suite: Automated PEST unit and feature test suite with 100% assertions coverage for critical modules.

Server Requirements

Ensure your Web Server (Apache or Nginx) satisfies the following server environment specifications:

Component Requirement Notes
PHP Version PHP 8.2.0 or higher Recommended: PHP 8.3 / 8.4
PHP Extensions BCMath, Ctype, Fileinfo, JSON, Mbstring, OpenSSL, PDO, PDO_MySQL, Tokenizer, XML Required for Laravel 12 core and Yajra DataTables
Database Server MySQL 8.0+ or MariaDB 10.5+ InnoDB storage engine with UTF8MB4 charset support
Web Server Nginx 1.20+ or Apache 2.4+ URL rewriting (`mod_rewrite` on Apache) enabled

Installation & Setup

Follow these steps to deploy and initialize the application on your server environment:

1 Clone and Install Dependencies

git clone <repository-url> cd cleaning-management composer install npm install && npm run build

2 Environment Configuration

Copy `.env.example` to `.env` and set your database connection details and application variables:

cp .env.example .env php artisan key:generate

3 Database Migration & Seeding

Execute migrations and seed default administrative accounts and system settings:

php artisan migrate --seed

4 Storage Link Creation

php artisan storage:link

Authentication & Security

The authentication layer provides secure access for administrators, sub-admins, and customers with strict role separation.

Role ID Role Name Default Dashboard Permissions & Boundaries
Role 1 Admin / Sub-Admin /admin-dashboard Full access to services, bookings, customers, sub-admins, settings, audit logs, and rewards.
Role 2 Customer /dashboard Booking wizard access, personal wallet, referral tracking, profile management, and review rewards.

Security Features

  • Email Verification: Unverified customers are redirected to /email/verify until email link is confirmed.
  • Welcome Credit Bonus: Verified customers automatically receive welcome wallet credits if enabled in settings.
  • Password Reset Flow: Secure tokenized email links via /forgot-password and /reset-password/{token}.

Sub-Admin Management

Super Administrators can grant administrative operational privileges to staff members through the Sub-Admin module (/sub-admins). Below is a step-by-step visual guide for each CRUD (Create, Read, Update, Delete) operation.

Sub-Admin Management Operations Overview

Action Feature / Button Purpose & Description
View Sub-Admins Sub Admins Menu / List Table View all registered sub-administrator staff accounts in the system.
Add Sub-Admin "+ Add Sub Admin" Button Create a new sub-admin staff account with login credentials and profile photo.
Edit Sub-Admin Edit (Pencil Icon) Button Update sub-admin name, email, phone number, profile photo, or reset password.
Delete Sub-Admin Delete (Trash Icon) Button Revoke and permanently delete a sub-admin staff account.

1. Sub-Admin Index Page (View List)

To view all existing sub-administrators, navigate to Sub Admins from the main admin sidebar (/sub-admins).

  • Data Listing: Displays customer avatar, full name, email address, phone number, created date, and action buttons.
  • Search & Filter: Use the live search box at the top right of the table to instantly filter sub-admins by name or email.
  • Pagination & Sorting: Sort columns dynamically and change visible records per page.

Sub-Admin Index List Interface

2. Create New Sub-Admin (Add Record)

To add a new staff member as a Sub-Admin, follow these steps:

  1. Click the blue "+ Add Sub Admin" button located at the top-right corner of the Sub-Admin index page.
  2. The Create Sub Admin Modal will appear on screen.
  3. Fill out the required information:
    • First Name & Last Name: Enter full staff name.
    • Email Address: Provide a valid, unique email address for login.
    • Phone Number: Contact number (optional).
    • Password & Confirm Password: Set account password.
    • Profile Photo: Optionally upload a profile photo (JPEG/PNG).
  4. Click "Save Sub Admin" to submit the form. Upon successful validation, the modal closes and the new sub-admin appears instantly in the table list.

Create Sub-Admin Modal Form

3. Edit Sub-Admin Details (Update Record)

To modify an existing sub-admin's details or credentials:

  1. In the Sub-Admins list table, find the target user row.
  2. Click the Edit button (pencil icon) under the Action column.
  3. The Edit Sub Admin Modal will open pre-filled with the user's existing details.
  4. Update any necessary fields (Name, Email, Phone, or upload a new Profile Photo).
  5. Password Note: Leave the password fields blank if you wish to keep the existing password. Fill in new password fields only if you want to reset the user's password.
  6. Click "Update Sub Admin" to save changes.

Edit Sub-Admin Modal Form

4. Delete Sub-Admin (Remove Account)

To delete a sub-admin user account from the system:

  1. Locate the sub-admin account in the Sub-Admins list table.
  2. Click the red Delete button (trash bin icon) in the Action column.
  3. A SweetAlert confirmation popup will ask: "Are you sure you want to delete this Sub Admin?"
  4. Click "Yes, Delete it!" to confirm permanent removal, or click "Cancel" to keep the account.

Delete Confirmation Popup Dialog

1. Weekly Schedule Overview List Page

Access Weekly Schedule from the main admin sidebar (/weekly-schedule) to review weekly business hours.

  • Days Displayed: Lists all 7 days of the week (Monday to Sunday).
  • Status Badges: Clearly marks days as Active (open for customer bookings) or Inactive (closed/off days).
  • Hours & Slots: Shows configured opening time, closing time, slot interval (e.g. 60 mins), and max simultaneous bookings per slot.

Weekly Schedule Overview Page

2. Edit Day Schedule & Shift Settings

To update the operating shift or time slots for a specific day (e.g. /weekly-schedule/monday/edit):

  1. Click the Edit button (pencil icon) next to any day row on the Weekly Schedule list.
  2. The Day Schedule Editor form will open:
    • Active Status Toggle: Enable to open cleanings for this day; disable to mark the day as closed.
    • Opening Time: The start of the working shift (e.g. 08:00 AM).
    • Closing Time: The end of the working shift (e.g. 06:00 PM).
    • Time Slot Duration (Minutes): Length of each appointment interval (e.g. 60 mins generates slots like 8:00 AM, 9:00 AM, 10:00 AM).
    • Max Bookings Per Slot: Maximum number of cleaning appointments allowed in the same time slot.
  3. Click "Update Weekly Schedule" to save shift changes.

Edit Day Schedule Page Form

3. Booking Wizard Integration (Step-2 Date & Related Time Slots)

The Weekly Schedule settings directly control customer availability and time slot generation during Step 2 of 4: Date & Time (/booking-service/date-time):

  • Day Selection & Related Time Slots: When a customer selects an active date on the calendar, the system automatically loads the time slots configured for that specific day of the week.
  • Dynamic Slot Generation: Available time slots (e.g. 8:00 AM, 10:00 AM, 12:00 PM, 2:00 PM, 4:00 PM) are generated strictly between the configured Opening Time and Closing Time based on the slot duration interval.
  • Inactive Days Guard: Off/inactive days toggled in the Weekly Schedule cannot be selected by customers.

Booking Wizard Flow

The 4-Step Booking Wizard (/booking-service/...) guides customers through a seamless, responsive checkout experience.

Step Route Title & Key Features
Step 1 /booking-service/create Service & Frequency: Select service type, frequency (one-time, weekly, bi-weekly, monthly), and questionnaire options.
Step 2 /booking-service/date-time Date & Time: Interactive 7-column calendar, schedule blackout checking, and time slot picker.
Step 3 /booking-service/your-details Your Details: Choose saved profile account details or enter manual address, suburb, postcode, and special instructions.
Step 4 /booking-service/review-confirm Review & Confirm: Apply referral/promo codes, review line-item cost breakdown, and confirm order placement.

Booking Operations

Manage customer bookings and lifecycle state transitions through the admin panel (/bookings).

Booking Lifecycle States

  • Pending Initial booking submission awaiting administrative approval.
  • Approved Booking verified and dispatched to cleaner schedule.
  • Completed Cleaning service completed. Triggers referral rewards if applicable.
  • Cancelled Booking cancelled by customer or administrator.

Referral System

Customers can invite friends using unique referral codes generated on their profile (/customer-referrals).

  • Unique Code: Auto-generated per user (e.g. REF-IRFAN99).
  • Checkout Redemption: New customers enter code during booking wizard step 4.
  • Automated Credit: When referred booking reaches completed status, wallet credits are automatically dispatched to the referrer.

Google Review Reward System

Customer incentive feature for Google reviews, guarded by EnsureGoogleReviewEnabled middleware.

Workflow & Security Rules

  1. Setting Feature Guard: Available only when google_review_enabled setting is set to true.
  2. Customer Submission: Customer requests reward proof via /my-review. Max 1 approved reward per customer.
  3. Admin Verification: Admin inspects review submission at /reviews/{review}/edit.
  4. Atomic Approval: Approving executes a database transaction crediting google_review_reward amount to user wallet and sending instant in-app notification.

System Settings & Feature Toggles

The System Settings page (/settings) allows Administrators to configure core company identity, operational booking rules, currency settings, reward values, and feature toggles in real-time.

System Settings Control Panel

Detailed Settings Configuration Guide

1. Company Identity & Branding
  • Company Name: Official business name displayed on customer receipts, page titles, and email templates.
  • Company Logo: Upload brand logo (PNG, JPG, WEBP, SVG). Dynamically updates header logo, sidebar, and documentation branding upon upload.
  • Phone & Email: Primary customer support hotline and contact email address.
  • Address: Physical address or headquarters location displayed on invoices.
2. System Timezone & Currency
  • Timezone: Sets the runtime PHP and Laravel timezone (e.g. America/New_York, Australia/Sydney). All booking calendar slots, daily schedules, and audit log timestamps evaluate against this setting.
  • Currency: ISO currency code and symbol (e.g. USD, $) formatted across pricing displays, totals, and wallet credits.
3. Operational Booking Rules
  • Minimum Booking Amount ($): Minimum cart total required before a booking can be placed.
  • Max Wallet Usage ($): Maximum dollar credit amount a customer can redeem from their wallet balance per single booking.
  • Maximum Advance Booking Days: Restricts how far into the future (e.g. 30 days) customers can schedule cleanings on the booking calendar.
  • Cancellation Notice (Hours): Minimum hours notice required (e.g. 24 hours) for free customer cancellations.
4. Rewards & Feature Toggles
  • Welcome Credit ($) & Toggle: Automated wallet bonus awarded to new customers upon completing email verification.
  • Referral Reward ($) & Toggle: Automated wallet bonus awarded to a referrer when their invited friend completes their first cleaning booking.
  • Google Review Reward ($) & Toggle: Master toggle and credit amount awarded to customers when an admin approves their Google Review reward request.
5. Promotions & Coupon Restrictions
  • Promotion Max Uses: System-wide default total redemption limit for new promotional codes.
  • Promotion Max Uses Per Customer: Maximum times an individual customer can redeem the same promotion (default: 1).

Promotions & Discount Coupons

Administrators create promotional discount codes under /promotions.

  • Discount Types: Fixed Amount ($ off) or Percentage (% off).
