# Customer Wallets & Transaction Ledger System

## 1. Feature Overview

The Customer Wallets module gives administrators complete visibility over customer wallet balances, credit sources, and debit redemptions.

Customers earn promotional credits via system events (Welcome Bonus, Referral Bonus, Google Review Reward) and can redeem them during checkout.

## 2. Visual User Guide

### 1. Customer Wallets Overview List Page
- **Visual Image Link**: [Customer Wallets List](https://snipboard.io/69MocK.jpg)

![Customer Wallets List](https://snipboard.io/69MocK.jpg)

**Key Features**:
- **Data Table**: Shows user name, email address, total credit badges (`+ $X.XX`), total debit badges (`- $X.XX`), and remaining balance.
- **Action**: Eye icon button opens the detailed wallet transaction ledger for that customer.

### 2. Customer Wallet Details View Page
- **Visual Image Link**: [Customer Wallet Details View](https://snipboard.io/a4ArhY.jpg)

![Customer Wallet Details View](https://snipboard.io/a4ArhY.jpg)

**Key Features**:
- **User Profile Summary Card**: Shows user avatar photo, full name, email address, phone number, and gender.
- **Wallet Financial Summary Card**: Displays credit sum, debit sum, and net remaining wallet balance.
- **Transaction History Table**: Itemizes every credit and debit transaction with source descriptor, timestamp, and administrative management actions.
